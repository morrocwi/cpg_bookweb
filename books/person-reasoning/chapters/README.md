# chapters/ — GENERATED (do not hand-edit)

These per-chapter files are generated from **morrocwi/cpg_book** by
`tools/build_articles.py` (workflow A). To change content, edit the source in cpg_book,
then rebuild — a rebuild OVERWRITES every `chapters/*.json`:

```
python tools/build_articles.py --book-dir <path-to-cpg_book> --web-root .
```

The site (`index.html`) reads `book.json` (manifest) + lazy-loads each chapter file.
